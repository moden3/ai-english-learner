# システム要件定義書

> **ステータス**: v1.1 確定版
> **更新日**: 2026-08-12
> **変更点**: 簡易APIキー認証の追加、AI連携の一括レスポンス化（和訳・構文解説・スラッシュ・重要単語を1リクエストで生成）、コスト最適化

---

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | AIを活用した英語学習サーバーレスAPI（仮称: ENG-APP） |
| 目的 | 英語の速読訓練・構文読解（スラッシュリーディング・和訳・構文解説）・重要単語把握をAIで支援する |
| 対象ユーザー | **自分専用（個人利用）** |
| 運用形態 | 個人開発・個人運用（コスト最小化） |
| 認証 | **簡易APIキー認証 (`x-api-key`)**（第三者の不正アクセス・AWS/Gemini課金防止のため） |

## 2. 機能要件

### 2.1 コア機能（AI連携・一括生成）

| 機能ID | 機能名 | 説明 |
|--------|--------|------|
| F-001 | 英文・解析データ一括生成 | レベルとトピックを指定し、**1回のAIリクエスト**で「英文本文」「スラッシュ分割」「セグメント別和訳」「構文解説」「重要単語」を一括生成する |
| F-002 | インタラクティブ読解支援 | フロントエンド上でスラッシュ区切りセグメントをクリックすると、対応する和訳と構文解説を表示する（クライアント側で処理） |
| F-003 | AIバックエンド連携 | Google Gemini API（無料枠）を呼び出して F-001 の全データを構造化JSONとして一括取得する |

### 2.2 トピック管理機能

| 機能ID | 機能名 | 説明 |
|--------|--------|------|
| F-004 | トピックリスト取得 | 英文生成で選択可能なトピック一覧を取得する |
| F-005 | トピックランダム選択 | 登録済みトピックの中からランダムに1件を選択して英文生成に使用する（デフォルト動作） |
| F-006 | トピック追加 | ユーザーがトピックリストに新しいトピックを追加する |
| F-007 | トピック削除 | ユーザーがトピックリストからトピックを削除する |

### 2.3 単語帳機能（データ永続化）

| 機能ID | 機能名 | 説明 |
|--------|--------|------|
| F-008 | 単語・フレーズ保存 | 一括生成された重要単語リスト等から、ユーザーが選択した単語・フレーズをDynamoDBに保存する |
| F-009 | 単語帳一覧取得 | 保存済みの単語・フレーズ一覧を取得する |
| F-010 | 単語・フレーズ削除 | 保存済みの単語・フレーズを削除する |

### 2.4 APIエンドポイント設計

すべてのエンドポイントでヘッダーに `x-api-key: <SECRET_KEY>` の付与を必須とする。

#### テキスト・AI系

| メソッド | パス | 機能ID | 説明 |
|----------|------|--------|------|
| POST | `/texts/generate` | F-001 | 英文・スラッシュ・和訳・構文解説・単語の一括生成 |

#### トピック管理系

| メソッド | パス | 機能ID | 説明 |
|----------|------|--------|------|
| GET | `/topics` | F-004 | トピックリスト取得 |
| POST | `/topics` | F-006 | トピック追加 |
| DELETE | `/topics/{topic_id}` | F-007 | トピック削除 |

#### 単語帳系

| メソッド | パス | 機能ID | 説明 |
|----------|------|--------|------|
| GET | `/vocabulary` | F-009 | 単語帳一覧取得 |
| POST | `/vocabulary` | F-008 | 単語・フレーズ保存 |
| DELETE | `/vocabulary/{id}` | F-010 | 単語・フレーズ削除 |

### 2.5 リクエスト/レスポンス仕様（POST `/texts/generate`）

**リクエスト**:
```json
{
  "level": "intermediate",       // "beginner" | "intermediate" | "advanced"
  "topic": "business",           // トピック名（省略時はランダム選択）
  "word_count": 200              // 目標語数（任意、デフォルト200語）
}
```

**レスポンス**:
```json
{
  "text_id": "uuid-xxxx",
  "level": "intermediate",
  "topic": "business",
  "title": "Effective Remote Communication",
  "full_text": "The quick brown fox jumps over the lazy dog...",
  "segments": [
    {
      "id": 1,
      "text": "The quick brown fox",
      "translation": "素早い茶色のキツネが",
      "grammar_note": "主語(S)。形容詞quickとbrownが名詞foxを修飾。"
    },
    {
      "id": 2,
      "text": "/ jumps over",
      "translation": "〜を飛び越える",
      "grammar_note": "動詞(V) + 前置詞(prep)。自動詞jumpにoverが続く。"
    },
    {
      "id": 3,
      "text": "/ the lazy dog.",
      "translation": "怠け者の犬を。",

      "word": "lazy",
      "meaning": "怠惰な、のんびりした",

      "example": "He is a lazy dog."
    }

  "created_at": "2026-08-12T12:00:00Z"
}
```

### 2.6 セキュリティ・認証仕様

- **認証方式**: 簡易APIキー認証（Header: `x-api-key`）
- **キー管理**: バックエンド側（SSM Parameter Store / Lambda環境変数）およびフロントエンド側（`.env`）で共通のシークレットキーを保持。
- **検証ロジック**: API Gateway または Lambda の冒頭でヘッダーの `x-api-key` をチェック。不一致の場合は `401 Unauthorized` を返し、後続処理（Gemini API呼び出し・DynamoDBアクセス）を遮断。
- **追加対策**: 
  - CORS設定で許可オリジンを限定。
  - API Gateway スロットリング（例: 5リクエスト/秒、日あたり上限1000リクエスト）を設定し、万一キーが流出しても大量課金を防ぐ。

## 3. 非機能要件

### 3.1 パフォーマンス

| 項目 | 目標値 | 備考 |
|------|--------|------|
| コールドスタート時間 | 1秒以内 | Rust採用 |
| API応答時間（P95） | 3〜5秒 | 一括生成のため1回あたりの生成量は増えるが、総待ち時間は劇的に減少 |

### 3.2 コスト目標（極限までの削減）

**目標: 完全月額$0**

- **Gemini API呼び出しの最適化**: 1回の英文学習につき **1回のみのAPIコール** に抑え、無料枠上限（15 RPM / 1,500 RPD）を余裕でクリア。
- **セキュリティ保護**: 簡易APIキー認証により外部からの不正スパムリクエストを遮断し、AWS/Geminiの予期せぬ課金を防ぐ。

## 4. アーキテクチャ概要

```
[Browser / SPA (Vite + React)]
            ^ (HTTPS / CDN)
            |
    [Amazon CloudFront]
            ^ (OAC)
            |
       [Amazon S3] (静的ファイルホスティング)

            | HTTPS / REST (Header: x-api-key)
            v
[Amazon API Gateway (HTTP API)]
            |
            | invoke (API Key検証)
            v
[AWS Lambda (Rust)]
            |
            +---> [Google Gemini API (Flash)]  (1リクエストで英文・スラッシュ・和訳・構文・単語を一括生成)
            |
            +---> [Amazon DynamoDB]          (単語帳・トピックデータの保存)
            |
            +---> [AWS SSM Parameter Store]  (APIキーおよびGemini APIキーの保持)
```
