# システム要件定義書

> **ステータス**: v1.3 確定版
> **更新日**: 2026-09-19
> **変更点**: 検索エンジン（Tavily AI Search API）の統合、最新ニュース参照ON/OFF機能、AIモデルの一本化（gemini-3.5-flash-lite）、記事語数の最適化（150〜250語）

---

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | AIを活用した英語学習Webアプリケーション（仮称: ENG-APP） |
| 目的 | 英語の速読訓練・構文読解（スラッシュリーディング・和訳・構文解説）・重要単語把握をAIで支援する |
| 対象ユーザー | **自分専用（個人利用）** |
| 運用形態 | 個人開発・個人運用（コスト最小化） |
| 認証 | **簡易APIキー認証 (`x-api-key`)**（第三者の不正アクセス・AWS/外部API課金防止のため） |

---

## 2. 機能要件

### 2.1 コア機能（AI・Web検索連携）

| 機能ID | 機能名 | 説明 |
|--------|--------|------|
| F-001 | 英文記事生成 | トピックを指定し、AI（Gemini 3.5 Flash-lite）を用いてプロ仕様のビジネス英語記事（150〜250語、TOEIC 800+ / CEFR B2-C1向け）を生成する。 |
| F-002 | 最新ニュース検索連携 (任意) | 生成時に「最新ニュースを参照する」をONにした場合、**Tavily AI Search API** を呼び出して直近3日間のニュース記事・URLを取得し、それを元に記事を生成（ソースURLを付与）。 |
| F-003 | 構文解析・単語抽出 | 生成された英文を対象に、「スラッシュ分割」「セグメント別和訳」「構文解説」「上級重要単語リスト（CEFR C1レベル）」をAIで抽出・生成する。 |
| F-004 | AIバックエンド連携 | Google Gemini API (`gemini-3.5-flash-lite`) を使用し、構造化JSONモードで高速・安定したデータ返却を行う。 |

### 2.2 トピック管理機能

| 機能ID | 機能名 | 説明 |
|--------|--------|------|
| F-005 | トピックリスト取得 | 英文生成で選択可能なトピック一覧を取得する |
| F-006 | トピックランダム選択 | 登録済みトピックの中からランダムに1件を選択して英文生成に使用する（デフォルト動作） |
| F-007 | トピック追加 | ユーザーがトピックリストに新しいトピックを追加する |
| F-008 | トピック削除 | ユーザーがトピックリストからトピックを削除する |

### 2.3 単語帳機能（データ永続化）

| 機能ID | 機能名 | 説明 |
|--------|--------|------|
| F-009 | 単語・フレーズ保存 | 一括生成された重要単語リスト等から、ユーザーが選択した単語・フレーズをDynamoDBに保存する |
| F-010 | 単語帳一覧取得 | 保存済みの単語・フレーズ一覧を取得する |
| F-011 | 単語・フレーズ削除 | 保存済みの単語・フレーズを削除する |

## 3. 非機能要件

### 3.1 パフォーマンス

| 項目 | 目標値 | 備考 |
|------|--------|------|
| コールドスタート時間 | 1秒以内 | Rust採用 + 起動時（`main()`）にSSMシークレットを一括キャッシュ取得 |
| API応答時間（P95） | 3〜5秒 | Tavily検索とGemini 3.5 Flash-liteを組み合わせ、語数を150〜250語に最適化して高速化 |

### 3.2 コスト目標（極限までの削減）

**目標: 完全月額$0**

- **Gemini 3.5 Flash-lite の一本化**: 記事生成・構文解析ともに軽量・超高速かつ無料枠の大きい `gemini-3.5-flash-lite` を採用し、API利用料をゼロに抑制。
- **Tavily AI Search API の無料枠活用**: 月間1,000回まで無料の検索特化APIを利用し、検索とLLM生成の責務を分離。
- **開発・テスト時のトークン節約機能**:
  - **ダミーモード**: ローカル開発時に環境変数（`USE_MOCK_AI=true`）やトピック名（`test` / `dummy`）、またはAPIキー未設定時に外部API通信を遮断しダミーテキストを返却。
- **セキュリティ保護**: 簡易APIキー認証により外部からの不正スパムリクエストを遮断し、AWS/Gemini/Tavilyの予期せぬ課金を防ぐ。
